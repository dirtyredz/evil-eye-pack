# Pack-test stage never refreshes preserve=true configs

Found during dk-f1f6d12d (2026-11-11): the pack-test stage installs packwiz preserve = true configs once and never refreshes them, so a config changed on main (config/jade/sort-order.json) stays stale in the local stage and run5 reported 240 findings from stale state. The ANU lane's stage also kept an old Connected Glass jar after its manifest was lost (cause not found). Workaround documented in docs/GOTCHAS.md: delete the stale file / the lane stage folder. Fix: the stage tooling should refresh preserve=true files (or wipe stale stage files) for pack-test runs. Acceptance: a pack test after a preserve=true config change sees the new bytes without manual stage cleanup.
