# Mekanism blocks placed by command expose no sided energy, so the showcase cable stays dead


Live showcase runs (2026-10-30, `artifacts/evil-eye-pack/jobs/2026-10-30-neoforge-phase7/showcase-mek-8` to `-12`): in the `mekanism_machines` section the creative energy cube (full, front east) and the enrichment chamber / crusher show no `Capabilities.EnergyStorage.BLOCK` on any of their six faces; only the unsided (null) lookup returns a store. The universal cable offers energy on every face. The same holds for an enrichment chamber placed by vanilla `/setblock` and for one given `Block.setPlacedBy` with a null placer, so it is not the showcase's NBT merge (which now keeps data components).

Effect: the cable never connects, so command-built Mekanism machines get no cable power. The section pre-charges both machines (20 kJ, two operations) so production still demonstrates the dedup survivor; transport is not asserted.

Next: check Mekanism's side-configuration default for blocks placed without an item (config component, `TileComponentConfig`), and whether a player-placed machine behaves differently in game (owner check). If placement needs the item's components, place Mekanism blocks with their default item components in the showcase.
