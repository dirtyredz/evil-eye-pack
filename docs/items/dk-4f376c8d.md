# Malware guard: skip unchanged jars by hash to cut pack-test scan time


From the 2026-10-24 malware guard rollout. Adding the static scan to the pack test made the pre-boot scan phase go from about 8-20 s to 54 s (a total run of about 255 s against about 223 s). Most jars are unchanged between runs.

Direction: cache scan results by archive sha256 (plus the signature and heuristics data version), and rescan only new or changed archives or a changed signature set. Verdicts must be identical to a full scan; add a test that forces a full rescan when the signatures change.
