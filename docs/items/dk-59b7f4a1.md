# Let the malware guard read Sable's LZ4-packed Rapier natives


Sable 2.0.6 bundles `sable_rapier` (jar-in-jar) whose native physics libraries ship as `natives/sable_rapier/sable_rapier_binaries.zip.l4z` (9 MB, LZ4 frame wrapping a zip). The malware guard scanned the jar clean (2210 files, 0 flagged) but cannot open the LZ4 frame, so the native binaries themselves were not inspected. Either add LZ4 frame decoding to the guard's archive walk or record a reviewed, hash-bound approval for that entry. Source: Sable's README says it is a lightly modified Rapier (github.com/ryanhcode/rapier).
