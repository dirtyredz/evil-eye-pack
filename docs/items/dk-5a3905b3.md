# Move hard-coded dedup policy out of dedup.js into data


From the 2026-10-23 push review (componentization and abstraction lenses, P2):

`kubejs/server_scripts/dedup.js` says it applies generated policy from `dedup.json`/`dedup_sources.json`, but it also hard-codes uranium smelting recipes and block-tag prefix rules (`cluttered:`, `createdeco:` except `createdeco:zinc_sheet`, and `farmersdelight:rope`). The generator and the duplicate guard can't see them.

- Move the uranium recipes into their own small server script or data files.
- Move the block-tag strip set into `dedup.json` (computed by `tools/dedup/overrides.cjs`) and have the script iterate it.
