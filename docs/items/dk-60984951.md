# migrate.mjs check reports Mekanism cache mismatch although the jar matches the lock


Found 2026-11-02 during the equipment-panel integration. `node tools/packwiz/migration/migrate.mjs check` on main fails with `MISSING mods/mekanism.pw.toml: cached artifact differs from the lock` plus two follow-on DEPENDENCY errors (interstellaris, mekanismgenerators require mekanism).

Evidence: the Mekanism-1.21.1-10.7.19.85.jar in the shared migration cache, the world-trial-final cache and the live Stable instance all have SHA-512 66745825…22b, identical to the pin and the lock's sha512. So the jar is correct; the check is comparing something else (sha1, size, or the .download.json sidecar). Stable is unaffected.

Fix: find which field the check compares, correct the stale record or the check, and make `migrate.mjs check` green on main.
