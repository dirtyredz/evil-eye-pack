# Pinning a jar does not stock the dev/migration jar cache


The dev/migration jar cache (env MIGRATION_MODS = artifacts/evil-eye-pack/migration/neoforge-1.21.1/cache/mods) is not stocked when a mod is pinned. On 2026-11-11 the Evil Eye Client 0.15.10 pin left it missing (0.15.5-0.15.9 never landed there either), so pack_test data tests (curios_cosmetic_slots, layout restore) failed with "Missing cached jar" until the release jar was copied in by hand (sha256 385bcdc5...8b9d verified).

verify_hashes only checks the Stable cache. Fix: stock MIGRATION_MODS in the same step that stocks the Stable cache (or have defaultJarDirs fall back to STABLE_CACHE), and make verify_hashes or the pin tooling report a missing dev-cache jar.

Acceptance: pinning a new jar leaves both caches holding it; a missing dev-cache jar is reported before tests fail.
