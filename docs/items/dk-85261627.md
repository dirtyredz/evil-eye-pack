# Decide how family clients get private-licence port jars


Owner ruling (via orchestrator, 2026-10-29): ports with a licence question (Alex's Mobs at least) stay in private repos with no public release. Stable and family clients install over plain HTTPS from the public pack feed, so a private jar needs a delivery route that does not publish it (for example a private authenticated host or a sideloaded jar). Development and trial use pin a local Valhalla jar by SHA-256. Must be decided before cutover.
