# Mark items as decor in game with a key


Mark items as decor in game: a rebindable key (default D) over a hovered item cycles its local override (automatic, decor, not decor); Shift+D does the same for its whole mod. Persists to config/emi-curation/decor-local.json, layered over decor.json.
