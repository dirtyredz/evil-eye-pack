# Review CE structure generation and legacy biome config equivalence

Ice and Fire CE uses config/iceandfire/iaf-common.json and iaf-client.json through Jupiter. The integration maps the old pack settings with direct equivalents (including all disabled griefing, dragon flute/bite/dig settings, mob weights/ranges, and 800-block spawn exclusion), and ships Jupiter defaults to avoid first-boot errors. Legacy TOML and biome JSON files are restored as requested but CE has no reader for those old biome filter files. CE structures use datapack structure sets plus per-candidate probabilities (dragon_cave spacing 18/separation 12, dragon_roost spacing 15/separation 6), so old 1/N per-chunk rates and 300-block inter-structure separation have no direct scalar equivalent. Keep CE native structure placement for integration; review distribution/biome intent before world-conversion acceptance, without pretending exact parity. Other removed legacy settings include Myrmex, glacier generation, pathfinding threads/debug, Bestiary font and Tinkers-only toggles.
